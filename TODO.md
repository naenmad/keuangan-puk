# Buatlah Halaman Khusus untuk Memanipulasi Excelnya.

1. Harus Upload File Excel Dulu
2. Setelah File Excel di Upload maka muncul dashboardnya.
3. Nantinya di dashboardnya itu ada beberapa fitur. Jadi bisa lihat grafik-grafik perbulan ataupun pertahun ataupun per kategori. Bisa juga edit data perbulannya langsung di dashboardnya.
4. Nah terus integrasi lah sama file generate_excel.py. Jadi nanti file excelnya diambil dari dashboardnya.
5. Kalo bisa fitur editnya bisa langsung edit yang di file excelnya. jadi ga takut lupa save atau lain sebagainya.
6. Siapkan projectnya untuk dihosting di vercel
